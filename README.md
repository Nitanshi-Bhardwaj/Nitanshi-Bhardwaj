I'm a **Master's student in Data Science at Columbia University** building practical, reliable, and human-centered AI systems.

My work focuses on **Generative AI, Machine Learning, LLM applications, RAG systems, AI automation, model evaluation, and responsible AI**. I enjoy turning ambiguous problems into working tools — from clinical workflow automation to hallucination detection and text-to-SQL agents.

## Featured Projects

### Hallucination Detection & Selective Abstention
Built an inference-time system that combines uncertainty signals to estimate hallucination risk and decide when an LLM should abstain.

### GitHub Issue Triage Agent
A RAG-based tool that classifies GitHub issues by label, severity, component, and duplicate candidates using structured JSON outputs.

### LLM SQL Agent
An agentic text-to-SQL workflow that converts natural-language business questions into SQL queries with guardrails and local deployment.

### Data Player
A real-time data-streaming application that converts CSV/Excel datasets into Open Sound Control streams for data sonification.
